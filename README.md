# VocalGym

Spoken English muscle-memory trainer built around structured Callan Method drills (Stages 1–12), featuring speech recognition, pacing timers, and AI-generated scene illustrations.

## Stack

- **Frontend:** React 19 · TypeScript · Vite
- **AI & Speech:** Gemini API (on-demand scene illustration & drill coaching)
- **Storage:** Firebase / Firestore

## Quick Start

```bash
npm install
npm run dev
```
